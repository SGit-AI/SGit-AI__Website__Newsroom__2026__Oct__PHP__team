Who might attack it

ActorWho they areWhat they can try
A publisher of a hostile pageWrites a page, a title or a tweet that a collector will capture.Script on the site (stored XSS); instructions to an agent (prompt injection).
Anyone on the internet, through a public laneHolds the published append tokens and public keys, like everyone.Forged feedback, subscriptions, telemetry; floods; text agents will read.
A steered agentOne of ours, after reading something it should have treated as material.Pushes to dev; messages as the editor; vault writes; releases.
A compromised dependency or actionA package, an action or a vendored library that changes under us.Secrets in CI; code in the build.
A malicious vaultA vault someone hands a reader or an agent.Settings, keys and text adopted as if they were the reader's own.
A curious server operatorAnyone who runs or logs a service we call.What we send in clear: IP addresses, write keys in headers, prompts.
Ourselves, by mistakeAn honest agent in a hurry, the security agent included.Secrets committed, controls that fail silently, rights granted by message.

PHP October 2026 (php.oct.2026.newsroom.sgit.ai) tracks PHP news for one month. This month that is one story, the two critical PHP security flaws, followed as evidence: every claim with a status and its sources, every source captured, dated and hashed into a private vault. Built and run by one editor and a team of software agents; the roles and the method are public, and the site is rebuilt from the vault, never written by hand. One of the SGit Newsroom's story sites: up from here are October 2026, the year and the newsroom, whose own section on the story is here. Part of the sgit.ai network.
